# The Handover — a poem about agency

One short poem about agency: the power to choose and to act, and what passes
between a person and the one who acts for them. The hands are lent; the
choosing stays.

Entry for the make.fun bounty `agency-poem-01`.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22+, standard library only. The program writes the poem to
`entry.txt`: UTF-8, under 1,000 characters, identical on every run.

## Files

- `main.ts` — the poem and the small program that writes and checks it.
- `LICENSE` — MIT.
